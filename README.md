# Lens — HTML & CSS Mini Project

Lens is a photography-themed sidebar navigation mini-project created as part of my frontend development learning journey.

The purpose of this project was to practise, apply, and revise the HTML and CSS concepts I have learned.

## https://lens-mini-project.netlify.app
(You can view the website here!!)

## About the Project

The project features a photography background with a sidebar navigation menu that opens and closes using HTML and CSS, without JavaScript.

It serves as a practical exercise in understanding how HTML structure and CSS styling work together to create an interactive user interface.

## Concepts Practised

- **HTML:** Page structure, elements, links, lists, labels, and checkbox inputs.
- **CSS selectors:** Class selectors, descendant selectors, pseudo-classes, and sibling combinators.
- **CSS positioning:** Absolute and fixed positioning.
- **CSS backgrounds:** Background images and `background-size`.
- **Typography:** Custom fonts and text styling.
- **UI styling:** Colors, transparency, shadows, and spacing.
- **Hover effects:** Interactive visual feedback.
- **Transitions:** Smooth sidebar opening and closing.
- **CSS-based interaction:** Using the checkbox `:checked` state to control sidebar visibility without JavaScript.

## Technologies Used

- HTML5
- CSS3
- Font Awesome icons
- Google Fonts

## How to Run Locally

1. Clone or download this repository.
2. Keep `index.html`, `style.css`, and `photo.jpg` in the same directory.
3. Open `index.html` in your browser.

No JavaScript, frameworks, or build tools are required.
